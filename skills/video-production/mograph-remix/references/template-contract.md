# Template contract

Every graphic, whether recreated from the source or newly designed for an edit, is written once as a **template** and reused three ways:
- **standalone**: preview and check it on its own
- **instance**: mount it as a sub-composition in an edit, with new values
- **library**: a self-playing single file in the template library.

`tpl.py` produces all three from one source file, as long as the source follows this contract.

## Folder

```
templates/<name>/
  template.hft      canonical source (HTML; .hft so HyperFrames doesn't treat it as a second root)
  template.json     moment card: WHEN to use this template (required)
  fonts/            TTF/WOFF2 files referenced by @font-face
  assets/           placeholder images/icons referenced by variables
  index.html        GENERATED by `$T standalone` — never edit by hand
```

Set the folder up with:

```bash
npx hyperframes init templates/<name> --non-interactive --example=blank
```

Then write `template.hft`. `$T standalone` overwrites the generated `index.html`.

## Moment card: `template.json`

Each template says when it should be used. The edit planner matches transcript moments against these cards, and the library shows them.

```json
{
  "kind": "stacked-tags",
  "mediaMode": "overlay",
  "duration": 4.8,
  "useWhen": ["list", "comparison"],
  "describe": "The speaker names 2–3 options one after another; each chip pops in as it is said.",
  "limits": "3 tags, ≤ 3 words each",
  "avoidWhen": "items are full sentences or more than 3"
}
```

- `useWhen`: 1–3 moments from the fixed vocabulary, best fit first. `$T moments` prints the vocabulary: hook, emphasis, list, steps, comparison, stat, flow, timeline, story, quote, definition, question, callout, cta.
- `describe`: one sentence about the exact spoken moment it illustrates, not what it looks like.
- `limits`: its capacity, as item counts, words per line and required photos.
- `avoidWhen` (optional): when a different graphic would be better.
- `mediaMode`: `overlay` (it sits on the footage) or `standalone` (it covers the picture). `duration` is the template's length.

## Rules (`$T check` enforces them)

1. **`__COMP__` placeholder.** Use it everywhere an identity is needed. `tpl.py` replaces it with `main`, an instance id, and so on.
   - root: `<div id="__COMP__-root" data-composition-id="__COMP__" data-start="0" data-duration="<s>" data-width="1920" data-height="1080">`
   - timeline: `window.__timelines["__COMP__"] = tl;`
   - **every** element id is `__COMP__-<name>`, and so is every `#id` in CSS and JS and every `getElementById("__COMP__-<name>")`. Dynamic ids keep the prefix too: `` `#__COMP__-item${i}` ``.
2. **Scoped CSS.** One `<style>` block goes in `<head>`. Every selector starts with `#__COMP__-root`, and `@font-face` / `@keyframes` stay top-level. Do not write `html`, `body` or bare `*` rules; standalone mode adds them.
3. **Root box.** `#__COMP__-root { position: absolute; inset: 0; }`.
   - **Overlay** templates leave the root transparent.
   - **Full-screen** templates paint their own background on the root.
4. **Variables.** Declare them on `<html data-composition-variables='[...]'>` with `id`, `type` (`string|number|color|boolean|enum`), `label` and `default`. Use the source's real content as the defaults.
   - Bind them declaratively where you can: `data-var-text="id"`, `data-var-src="id"`, and `var(--id)` in CSS. Every scalar variable becomes a CSS custom property.
   - Logic such as word splitting reads `window.__hyperframes.getVariables()` once, at the top of the script.
   - Images and icons are `string` variables holding a path such as `assets/icon-x.svg`.
5. **Fonts.** Write `@font-face { font-family: "X"; src: url("fonts/X.ttf") format("truetype"); font-weight: 100 900; }` for every named family. Download the closest Google Font as TTF:
   ```bash
   curl -sfL -o fonts/X.ttf "https://github.com/google/fonts/raw/main/ofl/<lowercase-family>/<File>%5Bwght%5D.ttf"
   ```
   Check the exact filename at github.com/google/fonts.
6. **Timeline.** Use one `gsap.timeline({ paused: true })` and load GSAP in `<head>` (`https://cdn.jsdelivr.net/npm/gsap@3.14.2/dist/gsap.min.js`). Use `fromTo` for entrances.
   - Hidden starting states go in CSS (`opacity: 0`) or inline on spans you create. Never use `tl.set(..., 0)`, because frame 0 ignores it.
   - Keep everything deterministic: no `Math.random`, no `Date`, no fetches.
7. **Length.** The root `data-duration` equals the timeline length, including the exit. An edit can make a slot longer; the last frame then holds, so an exited graphic just stays gone.

## Skeleton

```html
<!doctype html>
<html lang="en" data-composition-variables='[
  {"id":"headline","type":"string","label":"Headline","default":"Quit"},
  {"id":"accent","type":"color","label":"Accent","default":"#c8ebc0"}
]'>
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=1920, height=1080" />
    <script src="https://cdn.jsdelivr.net/npm/gsap@3.14.2/dist/gsap.min.js"></script>
    <style>
      @font-face { font-family: "Fraunces"; src: url("fonts/Fraunces.ttf") format("truetype"); font-weight: 100 900; }
      #__COMP__-root { position: absolute; inset: 0; }
      #__COMP__-root #__COMP__-chip { position: absolute; left: 116px; top: 200px; opacity: 0;
        background: var(--accent); font-family: "Fraunces", serif; font-size: 72px; padding: 22px 48px; border-radius: 24px; }
    </style>
  </head>
  <body>
    <div id="__COMP__-root" data-composition-id="__COMP__" data-start="0" data-duration="3" data-width="1920" data-height="1080">
      <div id="__COMP__-chip" data-var-text="headline">Quit</div>
    </div>
    <script>
      const tl = gsap.timeline({ paused: true });
      tl.fromTo("#__COMP__-chip", { opacity: 0, scale: 0.9 }, { opacity: 1, scale: 1, duration: 0.22, ease: "power2.out" }, 0);
      tl.to("#__COMP__-chip", { opacity: 0, duration: 0.15 }, 2.85);
      window.__timelines["__COMP__"] = tl;
    </script>
  </body>
</html>
```

## Verify a template

```bash
$T check templates/<name>                 # contract
$T standalone templates/<name>            # writes index.html
cd templates/<name> && npx hyperframes lint . && npx hyperframes check .
npx hyperframes snapshot --at <t1>,<t2>,<t3>    # opening, signature move, final hold
```

Read `snapshots/contact-sheet.jpg` and compare it against the reference frames. A contrast failure on a palette taken from the source is acceptable: keep the source colour and note it in INDEX.md. Fix every other failure.

## Commands

| Command | Effect |
|---|---|
| `$T instance templates/<name> <project> <inst> --values '{"headline":"New text"}'` | Writes `<project>/compositions/<inst>.html` (a sub-composition with `__COMP__` → `<inst>` and the values baked in), and merges `fonts/` and `assets/` into the project. |
| `$T lib-add <library> templates/<name> --meta '{"id","name","desc","features"}'` | Writes a self-playing copy to `<library>/Assets/templates/<id>.html` and adds or replaces its library entry. `duration`, `mediaMode`, `useWhen` and `limits` come from `template.json`, and "Use when: …" is appended to the description. |
| `$T catalog <templates_dir>` | Prints every template's moment card and variables, as input for edit planning. |
