# outreach/dm-revival/ — the DM lane's ledger

`dm-revival` writes `log.json` here on its first run: one entry per Instagram thread it handled
(`status`: sent | drafted | skipped, `reason`, `message`, `thread_url`, `date`, `sent_at`). It is
what makes the grind resumable across sessions and guarantees nobody gets the same revival DM
twice. Don't edit it by hand; delete it only if you want the skill to forget everything.
