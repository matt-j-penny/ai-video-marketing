# research/ — research reports

Every research skill writes one self-contained HTML report here per run and opens it:

- `IG-Competitor-Research_<YYYY-MM-DD_HHMMSS>.html` (ig-competitor-research)
- `YT-Competitor-Research_<YYYY-MM-DD_HHMMSS>.html` (yt-competitor-research)
- `YT-Feed-Research_<YYYY-MM-DD>.html` / `IG-Feed-Research_<YYYY-MM-DD>.html` (feed research)

Reports are never deleted or overwritten; each run is a new file. After a high-signal run, say
"compile knowledge" to fold the takeaways into `knowledge/`.
