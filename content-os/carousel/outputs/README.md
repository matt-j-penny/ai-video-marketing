# carousel/outputs/ — rendered Instagram carousels

Output of the `carousel-generator` skill, one folder per deck: `carousel/outputs/<slug>/` holds the
manifest (`carousel.json`), the AI cover variants (`cover/`), the final `slide_XX.png` set (2160×2700),
`contact_sheet.png`, and `caption.md`. Post the slide set + caption in the Instagram app (the
auto-poster is video/single-media only).
