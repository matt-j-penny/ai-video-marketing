# assets/face-refs/ — your face, for AI carousel covers (optional)

Only used by `carousel-generator` when a manifest sets `"face_refs": true` on the cover: `cover.py`
passes every image here to Higgsfield as identity references so the generated cover looks like you.

Drop **3-4 photos of your own face** here: square-ish, varied expressions/angles, well lit,
PNG/JPG/WEBP. Nothing else in the folder. If it's empty, covers generate without a person (or use a
typographic cover). No other skill reads this folder.
